# Student Grade System

A Java-based Student Grade Management System that allows users to manage student records and calculate grades.

## Features

- Add student records
- Store student IDs and names
- Enter student marks
- Calculate total marks
- Calculate averages
- Assign letter grades
- Determine pass/fail status
- Save and load student records from a file

## Technologies Used

- Java
- File Handling
- Arrays
- Methods
- Conditional Statements
- Loops
